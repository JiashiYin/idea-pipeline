**Terms used below (one gloss each).** *Prefix value V(h_t)*: the probability that the frozen agent, restarted from
its own state after step t, finishes the task; estimated by executing fresh continuations. *V-curve*: V(h_t) over t
for one failed run. *Anchored in-context critic (LVRL)*: a frontier model asked for the value of every step of a
trajectory, shown the group pass rate and summaries of k sibling runs, with step 0 pinned to the group pass rate and
the last step to the observed outcome after prediction. *Value captured VC_k*: the share of a run's total lost value
(from p(x) to 0) that lies in the largest drop within k steps of a proposed step. *Marginal-matched shuffle*: the same
critic scores permuted within the trajectory, so the score distribution is kept and only the placement is destroyed.
*Placebo (wrong-outcome) arm*: the same critic told the opposite ending and shown another task's siblings.
*Dollar-matched Monte-Carlo (MC) arm*: K fresh continuations per anchor costing what one critic call costs.
*Replay contrast (CWGT)*: the change in outcome when the policy's own alternative action at a step is executed forward.

### 1.1 arXiv 2608.19760 — Credit Without Ground Truth: Auditing Step-Level Credit Assignment in LLM Agents Against Executed Replay (v2, 2026-08-20) [full]

- **Trick.** Re-execute the policy's own alternative action at each step and roll forward; the shift in outcome is the
  step's contribution, and every credit signal is graded against it beside its own shuffled copy.
- **Ships.** 50 ALFWorld trajectories (Qwen2.5-7B-Instruct, temperature 0.7), 1,768 audited turns, 20,538 replay
  rollouts; three signal families: an LLM judge (Qwen2.5-72B, TARL prompt structure, {1, 0, −1} per step, **final
  outcome given in the prompt** — "3. Final Outcome: Whether the episode ended in task success or failure"), HCAPO's
  outcome-conditioned log-ratio ("Hindsight conditioning is a single outcome-injection line appended to the prompt — our
  addition, not HCAPO's", App. L), and the policy's confidence; a seven-arm training experiment with shuffled and
  inverted-ρ controls (Table 5).
- **Does not.** No sibling context, no endpoint anchoring, no frontier critic, no wrong-outcome placebo for the judge
  (the "inverted" arm inverts ρ, not the outcome shown to a judge), no dollar-matched MC arm, no SWE environment. Its
  judge is a per-step correctness scorer, not a value estimator.
- **Limitation text (§9, verbatim).** "Every scope condition below is measured, not assumed: the audit runs in a single
  environment with a binary outcome, and every claim is scoped accordingly. The training-loop experiments are
  single-family and single-scale (Qwen2.5-7B, LoRA (low-rank adaptation), offline)…" and "Our audit is confined to a
  single environment. We note, however, that ALFWorld is not an arbitrary choice…"; also "at balanced replica counts,
  the replay contrast is a positive rescaling of a return-derived step advantage evaluated at the factual action".
- **Code/data.** Run directories referenced in-text (`runs/collect v2/...`); no public URL found in the PDF.
- **Difference from the candidate.** Different signal class (per-step correctness judge vs anchored value critic),
  different environment, no placebo or MC arm. Not a replication → not killed here.

### 1.2 arXiv 2610.17633 — Executable Prefix Values for Locating Agent Failures (2026-10-13; Kean University / USF) [full]

- **Trick.** Restart the agent from reconstructed states of its own failed run and count how often it still succeeds;
  the step where that number falls is where the run was lost.
- **Ships (release opened today, `anonymous.4open.science/r/laf27`).** `data.tar.gz` (248 MB, 42k files):
  `base/<task>/<seed>.run.json` outcomes for all 1,200 base runs per policy, with the **selected trajectories'
  `.traj.json` (the agent's messages) and `.fingerprints.jsonl`**; `continuations/<traj_id>/t<step>/<seed>.run.json`
  (one record per continuation: outcome, not transcript); `derived.json` per curve (points, isotonic fit, t*, t_pnr);
  judge, LLM-annotator and human labels; `arms/qwen3.5-9b/` for the second policy; `configs/sampling.yaml`
  (temperature 0.7, top_p 0.8, top_k 20, thinking off); replay, continuation and analysis code; MIT license. README:
  "Raw agent transcripts (`.traj.json`) of unselected base runs, container snapshots, the judges' raw API responses and
  the eval cache are not included (several hundred GB); the `.run.json` files carry their outcomes." Collection cost
  stated: about 220 GPU-hours (123 for Qwen3.6-27B-FP8, 98 for Qwen3.5-9B) and about $116 of judge calls.
- **Already in print (Table 32 / Table 60, "Localizers by value captured").** Four judges, a human annotator, Claude Opus
  5.5 and GPT-6 Luna as annotators, and the fixed rules *first edit*, *step 1*, *random step*, *before first symptom*,
  *first verification*; e.g. random step VC0/VC1/VC3 = 0.01/0.04/0.10 on 47 curves; GPT-6 Astra 0.07/0.16/0.26. §6.6:
  "even the full schedule pins the decisive step exactly in only 28% of replications … at K = 32 a drop of 0.3 has a
  standard error of about 0.08 on each side". `analysis/cheap_v.py` is cheaper *schedules* (fewer continuations), not
  cheaper *estimators*.
- **Does not.** Grade any value estimator — no LLM critic, no linear decay, no self-estimate, no log-ratio; no
  successful-run curves; two policies of one family.
- **Limitation text (§Limitations, verbatim).** "Two policies of one family, one scaffold, one benchmark subset; V is
  relative to the agent and its budget (§6.9). The restart evaluation is offline and assumes a value-based policy never
  restarts a run that would have succeeded. Replay failures, the 31% of continuations that exhaust the shrinking budget
  and resampled killed runs are all counted and bounded by the controls (§6.10). The judges come from one vendor; one

  localizers and the value estimators controllers need can be built and ranked."
- **Difference from the candidate.** Supplies the ground truth and the random-step and fixed-rule rows (those arms are
  occupied: cite, do not re-run); grades no critic. The authors name our measurement as the next use of their curves,

### 1.3 arXiv 2610.15840 — LLM Value Functions for Credit Assignment in Agentic RL (LVRL; Apple; 2026-10-11) [full]

- **Trick.** Ask a frozen frontier model for the value of every step of an agent's run, pin the first value to the
  group's pass rate and the last to the observed outcome, and train on the differences.
- **Ships.** Prompts for rollout summarization and value prediction (App. C, Figs. 6–8: the context block "reports the
  success rate of the full rollout group and includes summaries of selected peer rollouts, excluding the target");
  AppWorld, BabyAI, SWE-bench Verified results; a Monte-Carlo check (App. F): M = 32 continuations from reconstructed
  AppWorld states, 114 events with |ΔV_MC| above a threshold set from σ = 0.125, sign agreement 44% / 78% / 88% by
  trajectory third; "none of the 114 selected events is a final transition, so this anchoring does not affect the
  reported agreement". No code release statement in the PDF.
- **Does not.** No shuffle, no placebo, no correlation with V_MC, no dollar-matched rollout arm; §4.5: "Although
  separating the effect of the endpoint anchors from that of the context rollouts, and varying the number of context
  rollouts, is left to future work, we hypothesize that performance improves with context size."
- **Limitation text (§Conclusion, verbatim).** "Querying a large LLM to predict step values for every trajectory during
  training can be prohibitive when training throughput or compute budget is constrained. Future work can investigate
  reducing this cost, for example, by querying the estimator only when its value signal is highly uncertain or by
  distilling its step-level knowledge into a smaller, learned critic."
- **Difference.** The critic under audit; its own check has no control arm and is on AppWorld, unreleased.

### 1.4 arXiv 2608.29685 — Last Step Matters: Early Uncertainty Cannot Predict Failure in Long-Horizon Agents (2026-08-30) [abstract-only]

- **Trick.** Score verbal confidence and perplexity at every stage of a deep-research run against the final outcome;
  they separate failures at the end (AUROC 0.85) and not at mid-run (none above 0.60 at 50% progress), because agents
  switch paths.
- **Difference.** Forward uncertainty, no executed value, no critic; it is the published precedent for the candidate's
  expected result on the self-estimate arm, which is therefore a replication row on SWE, not a finding.

### 1.5 arXiv 2610.18614 — Can an Agent Learn to Predict Its Own Failure? Outcome-Grounded Confidence Calibration (2026-10-13) [abstract-only]

- **Trick.** Train the agent's per-step verbalized confidence against the episode's realized outcome using the GRPO
  group as labels; AUROC rises from chance to 0.68–0.85 offline, and an evaluation protocol separates episode depth,
  task difficulty and attempt-level foresight.
- **Difference.** A trained self-estimate on ALFWorld/TextWorld/WebShop with group outcomes as truth, not executed
  V-curves; its depth/difficulty/foresight split is the protocol the audit's Spearman-by-third should copy.

### 1.6 arXiv 2609.33875 — Counterfactual Rollout Replay: Forkable Environments as Free Process Rewards for SWE Agents (v3, 2026-09-27) [abstract-only]

- **Trick.** At a few decision points restore the state, sample one alternative action, roll it forward, and use the
  return difference as the step's advantage; equal wall-clock on SWE-bench Verified gives 41.7% vs 36.7% for
  outcome-only GRPO.
- **Difference.** A training recipe, not an audit; it occupies the consequence "spend the budget on continuations at a

### 1.7 arXiv 2604.11037 — RTMC: Step-Level Credit Assignment via Rollout Trees (2026-04-13) [abstract-only]

- **Trick.** Group rollouts that pass through the same state and use their returns as per-step values, no critic.
- **Difference.** A free realized-sibling arm on the same benchmark; no comparison to a critic or to executed V.

### 1.8 arXiv 2602.05327 — ProAct: Agentic Lookahead in Interactive Environments (MC-Critic) (2026-02-05) [abstract-only]

- **Trick.** Calibrate a value estimate with lightweight environment rollouts inside PPO/GRPO on 2048 and Sokoban.
- **Difference.** MC-calibrated critic in the loop; no audit of a frontier critic; code public (GreatX3/ProAct).

### 1.9 arXiv 2602.17497 — Retrospective In-Context Learning for Temporal Credit Assignment (2026-02-19) [abstract-only]

- **Trick.** Have a pretrained LLM read a finished episode and write the advantage of each step; train on it (BabyAI).

### 1.10 arXiv 2606.08275 — Causal Agent Replay (2026-06-06) [abstract-only]

- **Trick.** Treat a run as a causal model, intervene on one step, re-execute forward, report the outcome shift with

- **Difference.** Tooling for attribution, validated synthetically; no critic graded.

### 1.11 arXiv 2608.22467 — The Variance of Thought (2026-08-23) [abstract-only]

- **Trick.** Policy variance Var_a Q(s,a) is the only source of return variance in a deterministic MDP; the MC advantage
  estimate at a fork with downstream success P has signal-to-noise of order √P, so its sample cost scales as 1/P.
- **Difference.** Theory; it prices step 0's resolution (low-p(x) tasks need more continuations) and is cited there.

- **Difference.** A forward estimator on the same policy family; an arm to grade if its monitor is released, not a
  competitor to the audit.

## 9. Checklist lessons (2026-10-20)

- A release's "code, curves and labels" is not the transcripts: open the README's data layout before costing an arm.
  2610.17633 ships the selected runs' transcripts and every continuation's outcome, but no sibling or continuation
  transcripts, so any arm that reads peers (LVRL's k summaries) needs regeneration (about 700 base runs here).
- Before proposing a control row against a released ground truth, read the release paper's own baseline table:
  2610.17633 Table 32 already prices random step, step 1, first edit and first verification by value captured; such
  rows are citations, not arms.
- When a critic's endpoints are anchored to the outcome, exclude anchored transitions from any late-trajectory agreement
  statistic (LVRL App. F.3 does; an audit that does not will overstate final-third skill by construction).
