Glossary (each term once). **Prefix cache** — the provider keeps the attention state of a prompt so a later prompt that begins with the
same tokens pays a discounted price for those tokens. **Cache read price $c$** — the price of a cached prompt token relative to an
uncached one (0.1 on most price lists; 0.025-0.05 on some). **Time-to-live (TTL)** — the time a cache entry survives without being
used before the provider deletes it. **Inter-request gap $\Delta\tau_t$** — wall-clock seconds from the end of model call $t-1$ to the
start of call $t$ in one run: tool execution, sandbox time, queueing. **Realized miss rate $m$** — the token-weighted share of requests
whose ideal hit (the tokens shared with an earlier prompt of the same run) is above the provider's minimum but whose provider-reported
cache-read count is zero. **Effective cache price** — $c_{\mathrm{eff}} = c + m(1-c)$, the expected price of a would-be-cached token.
**Observation masking (keep-ten)** — replacing tool outputs older than the latest ten with a placeholder. **Cache break** — an edit at
position $k$ of the prompt re-bills every token after $k$ once at the uncached price. **Warm-cache crossover $c^*_0$** — the cache
price below which rolling masking costs more than no management, $c^*_0 = (1+x)^{-1}$, $x = \bar R/(K(1+a/o))$, with $\bar R$ the
mean requests remaining, $K$ the kept turns, $o$ and $a$ the observation and reply lengths (2611.22238 Eq. 3; measured 0.21-0.55).
**Crossover with misses** — $c^*_m = \frac{(1-m) - xm}{(1-m)(1+x)}$, the probe's identity, equal to $c^*_0$ at $m = 0$. **Turn
boundary** — in a production coding agent, the point where the autonomous loop stops and waits for the human's next message. **Keep-alive**
— a dummy request sent to refresh a cache entry before its TTL. **Mis-integration** — harness code that fails to request caching or
misreads the usage fields, so the bill is uncached while the price list says cached. **HAL** — the Holistic Agent Leaderboard; its
archives hold one Weave log per run with every model call's inputs, provider usage and timestamps.

## 4. The $0 census: three HAL archives, run inside the search (checklist 2026-11-15)

message prefix with any earlier call of the task; requests with ideal hit under 1,024 tokens are excluded; a whole-request miss is a
provider-reported cache read of zero. The gap is $\Delta\tau_t$ = start of $t$ minus end of the predecessor that holds the prefix.
