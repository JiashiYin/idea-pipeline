Glossary (each term once). **Trigger**: the event that makes tau-bench compute a reward — the simulated user answering a
message with the stop token `###STOP###`, or the agent calling a terminating tool (`transfer_to_human_agents`). **Graded
fraction** $g$: the share of a cell's episodes on which the grader ran. **Trigger flip**: a task graded in one run and not in
the other. **Outcome flip**: a task graded in both runs with different rewards. **Replicate**: a second run of the same model
under the same scaffold and the same settings. **Reasoning-effort pair**: two runs of one model that differ only in the
provider's reasoning-effort setting (low/medium/high, or on/off) — a configuration contrast, not a replicate. **pass^k**: the
chance that all $k$ runs of a task pass. **Termination reason**: tau2-bench's per-simulation label for how an episode ended
(user stop, agent stop, max steps, too many errors, infrastructure error).

## 0. Verdict in one paragraph

**Killed at Gate 0 (premise hygiene); Gate 2B and Gate 4 fail behind it.** The headline's object does not exist: HAL's tau-bench
airline archives hold **no same-configuration replicate pair under the Generalist scaffold**. The "one or two runs of about 41
records each" per model that 2611.04399 pools (sec. 3.2) are reasoning-effort variants, named in the archive filenames
(`claude37sonnet20250219` vs `claude37sonnet20250219_high`; `high_reasoning_claudeopus41` vs `no_reasoning_claudeopus41`;
`high_reasoning___gpt5` vs `minimal_reasoning_gpt5`; `o4mini20250416_high` vs `o4mini20250416_low`; `claudeopus420250514`
vs `high_reasoning_claudeopus420250514`) and listed as separate rows in HAL's own Table A20 ("We ran 14 evaluations using 14
different language models and one agent scaffold (HAL Generalist Agent)", 2510.11977 A10.9). HAL's replicate protocol ($K = 5$,
temperature 0) was run on the **Tool-Calling** scaffold only ("For $\tau$-bench, we use a tool-calling scaffold", 2602.16666 sec. 4;
"We evaluate each benchmark with a single well-performing scaffold", sec. 7), where the grader fires in 98% of episodes, so the
"replicate disagreement and pass^k those cells report" is a quantity no HAL Generalist airline cell reports. The claim's
conditioning set was also wrong: the trigger is a draw from the user simulator, which tau-bench calls with **no temperature
argument** (`completion(model=self.model, custom_llm_provider=self.provider, messages=messages)`, `envs/user.py`) and HAL pins
to `gpt-4o` (`benchmarks/taubench.py`), so the provider default applies and HAL's temperature-zero sentence never covered the
party that decides whether grading happens. The pre-registered surprise fails Gate 2B: the paper ("the simulator usually does
not answer it with the stop token"), the disclosure ("rarely draws a `###STOP###`") and the HAL maintainers ("episodes that never
terminate are recorded as 0", a "lower bound") all read the trigger as a probabilistic event, and nobody in print holds that the
same tasks go ungraded on every rerun (2609.37315's "present on every rerun" is about tool defects). The consequence fails Gate 4:
the `if_true` remedy — grade on agent exit — is the disclosure's suggested fix 2 of 2026-09-03 verbatim ("Treat a Generalist
episode that ends on `respond` as terminal for grading, either by calling `isolated_env.calculate_reward()` when `done` is
still false or by routing the final response through the user simulator so `###STOP###` can fire"), and the `if_false` remedy —
the graded-fraction column — is the paper's check 1; both branches of the probe lead to the same shipped action, so its negative
teaches nothing (Gate 1's "both outcomes informative" clause). The pass^k-by-termination-bookkeeping complaint is already filed
on tau2-bench's tracker (#493 "pass^1 can report 100% from a single successful simulation after infrastructure errors are
excluded", 2026-08-28; #672, #517, #182), where every simulation carries a termination reason. Run on the one free dataset that
exists — the author's public per-record table over the five effort pairs — the probe's own statistics come out $\tau = 40/68 =
0.59$ trigger flips among stored-reward disagreements, $J = 0.46$, and $D_{\mathrm{pub}}/D_{\mathrm{all}} = 68/70 = 0.97$
(range 0.69 to 1.23): the "published disagreement inflated by the trigger" story does not hold even on pairs whose agents differ
by design, because grading everything removes trigger flips and adds as many outcome disagreements among the formerly
ungraded. No claim-worthy residue survives; one footnote does (section 6).

## 5. Gate-by-gate verdict

**Gate 0 — premise hygiene: FAIL (the killing gate).** (a) "Two archived runs of the same model" — the archive listing
(`huggingface.co/api/datasets/agent-evals/hal_traces/tree/main`, 381 entries, 47 airline) and the author's per-record table agree:
the five Generalist cells with two archives are effort pairs (default/high, high/no, high/minimal, high/low, default/high). Same
day, minutes apart, different settings. Number of same-configuration Generalist replicate pairs: **0 of 14 runs**. (b) "The
replicate disagreement and pass^k those cells report" — HAL's airline leaderboard reports single-run accuracy; its $K = 5$
consistency cells (2602.16666) are Tool-Calling, $g = 0.98$. The quantity is reported nowhere. (c) Conditioning set — the trigger
is a provider-default-temperature draw from `gpt-4o` (source), not "serving or simulator arithmetic" at temperature 0 as the
record wrote; the agent's temperature in the HAL Generalist archives is still unread, and HAL's temperature-zero sentence belongs
to a different paper and scaffold. (d) The decomposition — $G_{i1} \neq G_{i2}$ (grading indicator differs) is observable, but
"the instrument, not the agent" is not identified from it: the Generalist is graded when it calls `transfer_to_human_agents`,
an agent decision; a trigger flip can be the agent transferring in one run and closing in the other. The claim's headline
treats trigger flips and agent behaviour as disjoint causes; they are not.

**Gate 1 — cheap to kill: the probe exists ($150 for new runs, since the free pairs do not) but fails "both outcomes
informative".** Under $\tau$ high the remedy is grade-on-exit (shipped as a recommendation); under $\tau$ low the remedy is the
graded-fraction column (shipped). The same action follows either way; the negative outcome is not a footnote anyone would cite.

**Gate 2B — pre-registered surprise: FAIL.** The claim's "field assumes $\tau \approx 0$" is not the field's statement. The paper
says "usually", the disclosure says "rarely", HAL says "episodes that never terminate are recorded as 0"; all three read the
trigger as an event that sometimes fires. 2609.37315's "present on every rerun" concerns tool defects. There is no published
position that the ungraded set is a stable task property to be surprised against.

**Gate 3 — consumers:** one community (tau-family benchmark owners and HAL); their actions are already in motion (HAL notice;
tau2-bench termination reasons; open issues). No change of action follows from the number.

**Gate 4 — mechanism and consequence: FAIL** for the reason under Gate 1 — the consequence does not fork on the result; and the
mechanism sentence ("the stop token that triggers grading is the user simulator's reply") is 2611.04399 sec. 3.2 and the
disclosure's Item 2 verbatim.

**Gate 5 — durability:** the ruler would apply to any termination-gated grader, but tau2-bench already grades every ended episode
(premature endings scored 0, termination reason recorded), so the class of graders the ruler applies to is the original tau-bench
plus HAL's wrapper; the next benchmark refresh removes it.

**Gate 6 — ownership and timing.** Mechanism occupied by 2611.04399 (2026-11-03) and the disclosure (2026-09-03); remedy occupied
by the disclosure's fix 2 and the paper's check 1; the pass^k-denominator complaint occupied by tau2-bench #493/#672/#517. Why not
done (a replicate trigger share): no reason beyond the absence of replicates in the archive — a $150 run anyone can do, and the
HAL team can do on their Tool-Calling tracker protocol in a day. Race window irrelevant; nothing to race for.

**Position clause.** *Solo:* killed — no object on free data; the $150 version is a footnote. *Lab (HAL or the tau owners):* killed
as a claim; the measurement is a protocol service (run the Generalist under the $K = 5$ tracker and log the user's reply), and
the remedy is already on their queue (HAL's notice; tau-bench issue #92 open with no reply; tau2's termination reasons).

## 6. Consequence for the probes, and the residue

**C-W45-01 — killed with the claim.** Steps 0–1 as written have no data: zero Generalist replicate pairs exist. What its
statistics return on the five effort pairs, from the author's public table (Group A tasks, $n = 204$ task pairs):
$$D_{\mathrm{pub}} = 68, \quad \text{trigger flips} = 40, \quad \text{outcome flips} = 28, \quad \tau = 0.59, \quad J = 0.46,
\quad D_{\mathrm{all}} = 70, \quad D_{\mathrm{pub}}/D_{\mathrm{all}} = 0.97,$$
where $D_{\mathrm{pub}}$ is the number of tasks whose stored rewards differ between the two archives, $\tau$ the share of those
with different grading indicators, $J$ the Jaccard overlap of the two ungraded task sets, and $D_{\mathrm{all}}$ the number of
tasks whose rewards differ after the ungraded episodes are re-graded offline (per pair: 0.79, 1.20, 1.23, 0.93, 0.69). Read as
the claim would: trigger flips are the majority of stored-reward disagreements even between effort levels, and grading

## 7. Lessons for prompts/checklist.md (2026-11-08)

- "One or two runs per cell" in an audit paper are reasoning-effort levels until the archive listing says otherwise: HAL's
  airline archives name the effort in the filename, HAL's Table A20 lists them as separate rows, and the five two-archive
  Generalist cells 2611.04399 pools are all effort pairs. A claim whose quantity is a replicate statistic was filed on a
  leaderboard with zero replicate pairs. Fetch the host's file listing (`huggingface.co/api/datasets/<repo>/tree/main`) before
  writing "two archived runs"; fifth occurrence of "code, curves and labels are not the transcripts".
- The second party's sampling setting is read from the harness source, not from the benchmark paper's protocol sentence:
  tau-bench's LLM user simulator calls `completion()` with no temperature (provider default) and HAL pins `gpt-4o` as the user;
  HAL's "temperature zero" covers the agent and its Tool-Calling scaffold only. Any claim about temperature-0 variance on a
  user-simulator benchmark names the user's model and temperature or fails Gate 0 (applies to CL-W44-07's remaining clause).
- A grading indicator is observable but not an attribution: when the trigger set includes an agent action
  (`transfer_to_human_agents`), $G_{i1} \neq G_{i2}$ mixes the agent's choice with the simulator's draw; split the indicator by
  trigger type before writing "instrument, not agent".
- The complaint stream is reachable when repository endpoints are not: `gh api "search/issues?q=repo:<owner>/<repo>+is:issue+<words>"`
  returns titles and bodies for public repositories in this session. tau2-bench's tracker already carries the termination-category
  bookkeeping as pass^k complaints (#82, #182, #493, #517, #672); search it before writing "nobody has asked".
- A disclosure repository's per-record table is an enabling piece that replaces a decrypt-and-partition step 0:
  `corrections/2026-11-01/records_v2.csv` carries archive, model, task, recorded reward, graded flag and offline re-grade for all
  2,334 airline records; cost any HAL-airline probe against it first (C-W45-02's step 0 falls from two days to an hour).
- A claim seeded from one paper's mechanism sentence with a consequence equal to that paper's recommended fix cannot fork on its
  own result; check that the `if_true` and `if_false` actions differ from each other and from the seed paper's checks before
  grading Gate 4 (second occurrence after CL-W43-05).
