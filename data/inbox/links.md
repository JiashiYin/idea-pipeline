# Jacob's link inbox

Paste anything here, any time, from any device (the GitHub mobile app edits this file): an arXiv link or id, a Zhihu or X
thread, a sentence on why it caught your eye. One item per line. The next run or `/sprint scout` fetches each paper's
abstract, judges it by the counterfactual test (what common belief does it contradict?), files the keepers as scouts
with source `jacob-banter`, moves every processed line to `processed.md` with its verdict, and leaves this file empty.
A line that is an idea rather than a paper becomes a `/capture`.
